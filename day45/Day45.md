Today, I worked on app number 12 which is a Student Management System which has a GUI built with PYQT6. I sketched down a prototype and wrote down my project requirements on how the app's flow should look like. Before diving into building the application, I used today to build a simple age calculator app to get familiar with PYQT6 and how it works. The age calculator calculates a user's age based on the user's input of the name and the date of birth. I imported pyqt6 and its various components and since this is a simple application, I wrote one class for everything. The AgeCalculator class was a child class which inherited from the QWidget class from pyqt6 library. This class had two methods, the init method which initialiazed the QWidget super class(parent class) and initialized itself as well. The init method basically contained the structure for the gui and how the widgets were to be positioned so it was more or less the frontend. The second method which was calculate age method calculates the age based on the current year and the user input of date of birth and dispalys the results to the user. The app worked like I wanted it to and it gave me a good foundation for using pyqt6.

Also, I did a [side-project](./SP-Speed-Calculator-GUi/) which was an average speed calculator built with pyqt6. The app calculates the average speed based on the user input of time and distance and if the user wants the speed to be calculated in miles per hour or kilometers per hour. I wrote two methods inside a single class for this app. The init method was used to build the GUI interface and the calculate speed calculates the speed based on the user's inputs. The app worked like I wanted after testing it out.
