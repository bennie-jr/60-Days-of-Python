### DAY 47: Build an SQLite Student Management System with Python (Part 3)

Today, I completed app number 12. This is a Student Management System with an SQLite database.

Recap on what I did yesterday. I imported the the pyqt6 library with all the modules I would need for the GUI and I wrote a class which would contain everything GUI and this class inherited everything from the QMainWIndow from the pyqt6 library. The GUI was a simple UI with a table for the student information, a file menu dropdown with an add new student info item, an edit menu dropdown with search action for student search and a help menu which contained an about action item. I am using sqlite3 as my database so I created a database with a students table which will contain all student data. I also wrote another class just for inserting new student data, when the add student action is clicked on the UI , a dialog box opens asking for all the paramters of the new student data to be inputted and submitted. When this new student data is submitted it is then inserted into the database table and appends a new row to the table on the UI. The last class I added was for the search functionality. When the search action button is clicked a new dialog box opens where you can type in the students full name and when the search button is clicked the row the students data is found on is highlighted. The search is done in the database table and the results that it returns is turned into a list which will then be used by the pyqt6 to match what is on the table and highlights it. Today, I added more to the GUI and add their functionalities as well. I added a toolbar which acted like a shortcut to things from the menu bar and these were the add student button and search student button, I used images as representation buttons and added a click event which would trigger their functionalities respectively. I also added a status bar which had two buttons, an edit button and a delete button. These two buttons are not visible at first but once a user clicks on any of the rows or columns on the table, these buttons will appear and as the names imply, edit will edit the data of the row you clicked and the delete will delete that row. The edit button when clicked opens a dialog box where you can edit the existing students data and once you update the info the database and table in the gui is updated. For the delete button I added a confirmation dialog box and confirmation message when the user confirms deletion. I also added an About dialog box which shows up when the About button on the menu bar is clicked, the dialog just gives you a brief description on what the app is about.

Also I learnt more about code refactoring and a concept called code smells, how to identify them and fix them in your code base.

Day 47 was good, I am learning more and more each day.
