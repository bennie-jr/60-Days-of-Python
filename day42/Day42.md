### DAY 42: Build a Hotel Booking App in OOP Style with Python(Part 2)

Today, I continued to build on my understanding of OOP by extending the code of the Hotel Booking App and adding new features.

Recap on what I did yesterday. I started building the Hotel Booking app with OOP. I imported pandas and read the csv file. I created 2 class, Hotel class and ReservationTicket class. I had 3 methods in the Hotel class, the init method , the book method and the available method. The book method booked the hotel by using the hotel id provided by the user to change its availability from yes to no and the available method checked if the hotel was available. The reservationTicket method had two methods, the init method and the generate method which generates a booking ticket for the user. I then implemented the methods of the hotel and reservation ticket classes and the logic worked like this, the code asks the user to input the id of the hotels available and the app checks if the hotel is available. If the hotel is available it then books the hotel, asks for the users details like name and uses it to generate the reservation ticket. If the hotel isn't available the user gets a prompt. Today, I added two new features to the code, the credit card feature and the secure credit card feature. Since this wasnt a webapp I need to simulate a user adding a credit card without it getting too complicated. So I had two data sources the cards csv file and card security csv file these contained dummy credit card info and credentials. I used pandas to read both files and saved them in variables. I wrote two classes, CreditCard class and SecureCreditCard class. The CreditCard class contained two methods, the init method which accepted the credit card number as a parameter and the validate method which checks the credit card info provided by the user against the data in the csv file and returns True if it is valid. The SecureCreditCard class(child) inherited the CreditCard class(parent) and had only one method the authenticate method which checks the given user password against the passwords in the csv and returns True if it is valid. So this is how these new classes and methods fit into the code logic we had so far. If the hotel is available then we instantiate the SecureCreditCard class since its inheriting the CreditCard class. Then the app checks if the credit card details provided by the user is valid by calling the validate method and if its valid then the app checks if the password the user provided is correct by calling the authenticate method if the credentials is correct the the app books the hotel and generates the Reservation ticket. If at any step the info is wrong we print a message to the user to try again. The app run like it was supposed to after a few tests.

I added two classes, the SpaHotel class which inherits the Hotel class and the SpaReservation class. The SpaReservation class has a generate method which generates the SPA reservation ticket. I added the logic after the Hotel Reservation ticket is generated then if the user wants SPA reservation then that ticket is also generated. I was able to complete it and the app works perfectly.
