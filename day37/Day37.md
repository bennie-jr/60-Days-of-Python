### DAY 37: App 9 - Build a Webcam Alert App with Python(Part 2)

Today, I finished building app number 9 which is Webcam Alert App. The app basically sends you an email alert whenever it detects objects moving in your webcam.

Recap on what I did yesterday. I started building app number 9 which the Webcam Alert App. I worked on the main part of the app which detects motion today. I used cv2 to capture the webcam video and I had to reduce the pixel BGR(blue, red, green)matrix of the frames to a minimun by converting the quality to grayscal and blurring the pixel quality a bit with GaussianBlur method. Next, to be able to get the detection of objects I had to compare the first frame with the consecutive frames. I had to get put a rectangle on the moving or new objects that enter the video. I got the trigger action to work by having two status numbers 0 and 1. I created an empty status list which the program kept appending the status numbers to, I got the last two status numbers in the list and used an if statement to compare the last two numbers this will indicate when a moving object entered the frame and email alert had to be sent. I was able to get this process to work. Today, I worked on the emailing part which sent an email with a picture attachment of the moving object in the frame. I imported the smtplib module and wrote a function with an argument that takes the image_path of the image to be sent and uses it as an attachment before the email is sent. Now the difficulty I faced was being able to get one image to send as an attachment because there were a lot of images captured since the images were frame by frame of the webcam video, so to narrow it down to a single image I placed the images in a folder and used glob to get a list of all the images in the folder and picked the middle image file out of the total images in the folder. After this, I faced another issue where the camera kept freezing for sometime when the email function was running. I discovered that these two process (email and webcam motion detection) were running at the same time and the webcame freezing was a way to get the email function running as well. To fix this issue, I used a concept called Threading. Threading comes in handy when you are running two or more processes at the same time and you need a separation, threading helps you by running some of the processes in the background. I used the threading class from the imported thread module and I used threading to run the email function as a background process freeing the webcam motion detection process to run freely without any interruptions. I also wrote a function which cleaned(deleted) all the images in the images folder once the email had been sent. I also put this function in threading to run as a background process just before the process breaks when the user quits the program. The program worked like I wanted it to and the emails were sent successfully. App number 9 has been completed.
