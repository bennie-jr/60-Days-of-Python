### DAY 51: Build a Web App with Flask Python (Part 2) 

Today, I worked on web development. I finished building app 14 which is a Job Application Form built with flask.

Recap on what I did yesterday. I set up my environment and created the app structure, flask follows a specific file and folder structure. I wrote a simple flask app implementation for the backend which routes http requests to the frontend(index.html) file in the templates folder. I started building the frontend and wrote the html code for how I wanted the job application form to look like. I used bootstrap for the css styling and I was able to finish the frontend.

Today, I added functionality to the backend and completed the app. I started off with getting the input user data from the form on the frontend. I was able to get that by adding a name parameter to the input elements and created a variable for each input and used the flask request.form method to get the data. I then proceed to add a database to the app to store user data. I used sqlite3 and sqlalchemy for this, I imported the flask sqlalchemy module and instantiated the sqlalchemy class with the flask app as a parameter. I created a class Form for the database model where I added my database table schema. The Form class was then called in my main app function with the variables for the user input as parameters and this was used to write the user data into the database table. I also added a submission notification message to the frontend once the user hits submit. I used jinja2 in the html code to call the flash message I wanted to display from my backend. The last thing I did was add a sending confirmation email functionality after the user submits the form. I used the flask mail module for sending of the email after adding the smtp logins and email message template of course. I was able to test the app after I was done and everything worked like I wanted it to.

Day 51 was good, I am learning more and more each day.
