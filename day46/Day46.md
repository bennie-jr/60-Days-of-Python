Today, I started working on the app itself. I started working on the GUI first with pyqt6. I am using sqlite3 as my database so I created a database with a students table which will contain all student data. When this new student data is submitted it is then inserted into the database table and appends a new row to the table on the UI. The last class I added was for the search functionality. When the search action button is clicked a new dialog box opens where you can type in the students full name and when the search button is clicked the row the students data is found on is highlighted. The search is done in the database table and the results that it returns is turned into a list which will then be used by the pyqt6 to match what is on the table and highlights it.
